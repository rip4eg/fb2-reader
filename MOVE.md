# Перенос на другой компьютер

Короткая шпаргалка. Подробности — в `README.md`, раздел «Перенос на другой компьютер».

## 1. Просто читать книги

Переносить ничего не нужно. Откройте на новом компьютере ссылку из читалки
(Настройки → «Скопировать ссылку») — библиотека и позиции чтения приедут сами,
они хранятся в GitHub.

## 2. Работать с кодом

```powershell
npm install     # jsdom и fake-indexeddb — только для тестов
npm test        # 226 проверок
npm start       # http://127.0.0.1:8080/
```

Нужен только [Node.js 20+](https://nodejs.org/). Сборки нет: файлы отдаются как есть.

## 3. Публиковать обновления

```powershell
node tools/publish.mjs --token=ВАШ_ТОКЕН --repo=fb2-reader --data-repo=fb2-data
```

Без Node.js (только Windows, средствами PowerShell):

```powershell
.\tools\push-to-github.ps1 -Token ВАШ_ТОКЕН -Repo fb2-reader
```

## Что не нужно переносить

- **Книги, обложки, прогресс чтения** — они в приватном репозитории `fb2-data`.
- **`node_modules`** — ставится заново одной командой.
- **Токен** — он хранится в браузере, на новом устройстве вводится заново
  (Настройки → «Отключить» → вставить токен).

## Если что-то не так

- `npm install` не проходит — проверьте, что установлен Node.js 20 или новее
  (`node --version`).
- Тесты падают с «Cannot find module jsdom» — не выполнен `npm install`
  или `node_modules` скопирован с другой системы; удалите его и поставьте заново.
- Публикация отвечает 403/404 — у токена нет прав на запись в репозиторий читалки.
