# Читалка FB2 с синхронизацией позиции чтения

Веб-читалка, которая живёт на GitHub Pages, а библиотеку и прогресс хранит в вашем
приватном репозитории GitHub. Открыли книгу на телефоне — на компьютере она
откроется на том же месте.

**Умеет:**

- открывать `.fb2` и `.fb2.zip` (в том числе в кодировке Windows-1251);
- хранить библиотеку в приватном репозитории и подтягивать её на любом устройстве по одной ссылке;
- синхронизировать позицию чтения: «абзац + доля внутри абзаца», поэтому место не сбивается
  при смене размера шрифта, устройства или ориентации экрана;
- показывать процент прочитанного по каждой книге и «Продолжить чтение»;
- три фона: **белый**, **сепия** (цвет старой пожелтевшей бумаги) и **чёрный**,
  плюс режим «как в системе»;
- настраивать шрифт (с засечками / без / моно), размер, интервал, ширину колонки,
  выравнивание и переносы;
- оглавление, сноски в отдельном окошке, обложки, картинки, таблицы, стихи, цитаты;
- читать офлайн (оболочка приложения и книги кэшируются в браузере);
- устанавливаться на телефон как обычное приложение (PWA).

---

## Как это устроено

```
        ┌──────────────────────────┐
        │  GitHub Pages (статика)  │   ← сам интерфейс читалки, публичный репозиторий
        └────────────┬─────────────┘
                     │  запросы к api.github.com с вашим токеном
                     ▼
        ┌──────────────────────────┐
        │ Приватный репозиторий    │   ← книги, обложки, прогресс
        └──────────────────────────┘
```

Сервера нет вообще. Приложение — статические файлы на GitHub Pages, вся «база данных» —
файлы в вашем приватном репозитории:

```
library.json                 список книг (название, автор, файл, обложка, размер)
books/<id>.fb2               сами книги
covers/<id>.jpg              обложки (если были в файле или загружены вручную)
progress/<устройство>.json   позиция чтения и настройки этого устройства
```

Каждое устройство пишет **только свой** файл прогресса, поэтому конфликтов записи
не бывает: при открытии книги читалка смотрит все файлы прогресса и берёт самую
свежую запись. Если книга открыта на двух устройствах одновременно и на втором
появилась более новая позиция — придёт уведомление с кнопкой «Перейти».

## Шаг 1. Репозиторий для книг (приватный)

1. Откройте <https://github.com/new>.
2. Имя: например `fb2-data`. Видимость: **Private**.
3. Поставьте галочку **Add a README file** (чтобы сразу существовала ветка `main`).
4. Create repository.

## Шаг 2. Токен доступа

1. Откройте <https://github.com/settings/personal-access-tokens/new>
   (это fine-grained token — он даёт доступ только к выбранным репозиториям).
2. **Token name:** `fb2-reader`.
3. **Expiration:** удобный срок (например, 1 год). Когда истечёт — нужно будет создать новый
   и один раз переподключиться.
4. **Repository access** → *Only select repositories* → выберите `fb2-data`.
5. **Permissions** → *Repository permissions* → **Contents** → `Read and write`.
   Больше ничего включать не нужно.
6. Generate token и скопируйте строку вида `github_pat_...`
   (она показывается ровно один раз).

> Токен позволяет читать, изменять и удалять файлы только в этом одном репозитории.
> Хранится он лишь в браузере того устройства, где вы его ввели, и внутри ссылки,
> которую вы себе сохраните.

## Шаг 3. Публикация читалки

**Способ А — скриптом** (нужен Windows PowerShell, git не требуется):

```powershell
cd tools
.\push-to-github.ps1 -Token github_pat_ВАШТОКЕН -Repo fb2-reader
```

Если PowerShell блокирует запуск скриптов:

```powershell
powershell -ExecutionPolicy Bypass -File .\push-to-github.ps1 -Token github_pat_ВАШТОКЕН -Repo fb2-reader
```

Скрипт создаст публичный репозиторий `fb2-reader`, зальёт в него файлы читалки и
включит GitHub Pages. В конце он напечатает адрес вида
`https://ваш-логин.github.io/fb2-reader/`.

**Способ Б — вручную:**

1. Создайте **публичный** репозиторий, например `fb2-reader`.
2. Загрузите в него содержимое папки `fb2-reader` (можно просто перетащить папки
   `js`, `css`, `tests`, `tools` и файлы `index.html`, `sw.js`, `manifest.json`,
   `icon.svg` в веб-интерфейс GitHub).
3. Settings → Pages → *Build and deployment* → Source: **Deploy from a branch**,
   Branch: **main**, папка **/(root)** → Save.
4. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/fb2-reader/`.

> Репозиторий приложения должен быть публичным: GitHub Pages для приватных
> репозиториев доступен только на платном тарифе. Секретов в коде нет —
> данные лежат в отдельном приватном репозитории.

## Шаг 4. Первое подключение

1. Откройте адрес читалки.
2. Заполните:
   - **Владелец** — ваш логин GitHub;
   - **Репозиторий для данных** — `fb2-data`;
   - **Ветка** — `main`;
   - **Токен** — `github_pat_...`.
3. «Проверить и подключить». Приложение создаст в репозитории `library.json`
   и покажет **ссылку для других устройств** — в ней зашит токен.

   Сохраните эту ссылку в закладки. Именно по ней открывайте читалку на всех
   устройствах — ничего вводить не придётся.

## Шаг 5. Телефон

1. Откройте сохранённую ссылку в Chrome (Android) или Safari (iOS).
2. Меню браузера → **Добавить на главный экран** / **На экран «Домой»**.
3. Запускайте с иконки — откроется без адресной строки, как обычное приложение.

## Как пользоваться

**Добавить книгу.** Кнопка «＋ Добавить книгу» → выберите один или несколько
файлов `.fb2` / `.fb2.zip`. Читалка разберёт их, покажет названия и авторов из самих
файлов, затем загрузит в репозиторий. После загрузки книга сразу доступна на всех
устройствах.

**Читать.** Нажмите на книгу. В шапке читалки: `←` выход, `☰` оглавление,
`◐` смена фона, `Aa` настройки текста. Внизу — полоса и процент прочитанного.

- Мышь/клавиатура: `←` `→` — страницы, `Space` — вперёд, `Home`/`End` — начало и конец,
  `Esc` — выйти из книги.
- Тап по тексту скрывает/показывает панели, чтобы читать «во весь экран».
- Кнопка `✕` на карточке книги: скачать файл обратно, переименовать,
  заменить обложку, начать заново (сбросить позицию на всех устройствах), удалить.

**Фон.** Три варианта — белый, сепия (тёплый желтоватый, как старая бумага),
чёрный — плюс «как в системе». Кнопка `◐` переключает их по кругу, полный список есть
в настройках. Там же шрифт, размер, интервал, ширина колонки, выравнивание и переносы.
Настройки оформления синхронизируются между устройствами.

**Проценты.** В библиотеке у каждой книги видна полоса прочитанного. Книга считается
прочитанной при 99,5 %.

## Синхронизация: как это работает на практике

- Позиция уходит в репозиторий автоматически: не реже, чем раз в 12 секунд чтения,
  и сразу — при выходе из книги, сворачивании вкладки или нажатии кнопки «⟳».
  Внизу читалки видно состояние: «сохранено», «есть несохранённое», «сохраняю…».
- Сохраняется то место, где вы находитесь сейчас. Если пролистали вперёд,
  посмотрели и вернулись назад — сохранится место, куда вернулись.
- Раз в минуту (пока вкладка открыта) читалка проверяет, не появилось ли более
  свежей позиции с другого устройства.
- Если позиция «оттуда» новее, появится уведомление с кнопкой **Перейти**.
- Книги и обложки кэшируются в браузере, поэтому повторное открытие мгновенное,
  а уже прочитанные книги доступны без интернета.

## Безопасность

- Токен даёт доступ только к одному репозиторию (`fb2-data`) и только к разделу Contents.
- В ссылке токен лежит во фрагменте после `#`. Фрагмент не отправляется на сервер
  и не попадает в заголовок Referer при переходах по ссылкам.
- Не публикуйте ссылку с токеном и не пересылайте её в мессенджерах.
- Если ссылка утекла: отзовите токен на <https://github.com/settings/tokens?type=beta>,
  создайте новый и подключите его заново (Настройки → «Отключить», затем введите новый).

## Ограничения

- GitHub Pages — статический хостинг: интерфейс не умеет работать без api.github.com.
- Бесплатный лимит запросов к GitHub API — 5000 в час (обычное чтение тратит 2–5 запросов
  в минуту).
- Рекомендуемый размер репозитория — до 1 ГБ, отдельного файла — до 100 МБ.
  Этого хватает на несколько тысяч книг.
- Если у вас включён жёсткий блокировщик рекламы или корпоративный прокси,
  запросы к `api.github.com` могут не проходить — тогда синхронизация покажет «офлайн».

## Разработка

Структура:

```
index.html            точка входа
css/style.css         темы и оформление
js/app.js             запуск, маршрутизация, периодическая синхронизация
js/config.js          настройки, разбор ссылки с токеном, темы
js/gh.js              клиент GitHub REST API (дерево, блобы, атомарные коммиты)
js/store.js           библиотека и прогресс, два бэкенда: GitHub и локальный
js/fb2.js             разбор и отрисовка FB2
js/zip.js             распаковка .fb2.zip
js/position.js        позиция чтения (блок + доля внутри)
js/library.js         экран библиотеки
js/reader.js          читалка
js/settings.js        настройки и первичное подключение
tests/                тесты: парсер, позиция, хранилище, сквозной сценарий
tools/                скрипт публикации на GitHub
```

Сборка не нужна: это обычные ES-модули, файлы отдаются как есть.
Локальный запуск — любой статический сервер из корня проекта:

```powershell
python -m http.server 8080
# затем http://127.0.0.1:8080/
```

Тесты:

```powershell
node tests/node-tests.mjs     # парсер FB2, zip, кодировки, позиция, конфиг
node tests/store-tests.mjs    # хранилище и синхронизация на mock-сервере GitHub
node tests/smoke-tests.mjs    # весь путь: запуск, добавление книги, читалка, темы, сноски
```

Для двух последних нужны `jsdom` и `fake-indexeddb`:

```powershell
npm install --no-save jsdom fake-indexeddb
```

Тестовые файлы FB2 генерируются скриптом `tests/make-fixtures.py`
(нужен Python 3).

В браузере те же проверки открываются страницей `tests/run.html`
(там они прогоняются на настоящей вёрстке).

## Частые вопросы

**GitHub показывает ошибку 404 при подключении.**
Проверьте имя владельца и репозитория и что токену выдан доступ именно к этому
репозиторию (Repository access → Only select repositories).

**«Токен не принят GitHub (401)».**
Токен истёк или скопирован не полностью. Создайте новый и подключите заново.

**Приложение пишет «офлайн», хотя интернет есть.**
Чаще всего это превышенный лимит запросов (5000/час) или блокировка `api.github.com`
расширением браузера. Показанная библиотека при этом приходит из кэша.

**Книга не открывается.**
Скорее всего, файл не FB2. Откройте его блокнотом: он должен начинаться с
`<?xml ...?>` и содержать тег `<FictionBook>`.

**Как перенести книги, если я больше не хочу пользоваться читалкой?**
Все книги лежат в репозитории `fb2-data` в папке `books/` в исходном виде —
их можно просто скачать.
